## Desteklenen Sürümler / Supported Versions

| Sürüm | Destek |
|-------|--------|
| `main` branch | ✅ Aktif |

## Güvenlik Açığı Bildirme / Reporting a Vulnerability

**Güvenlik açıklarını lütfen public Issue olarak açmayın.**

Bir güvenlik açığı keşfettiyseniz:

1. GitHub'da **Private Security Advisory** açın:
   `https://github.com/egemenxgul/No-iz/security/advisories/new`

2. Veya doğrudan GitHub profili üzerinden iletişime geçin.

Bildiriminiz 48 saat içinde yanıtlanacaktır.
